## 🚀 نظرة عامة على النظام والمميزات المطورة

**Kernel Ping Center** يربط بين سرعة خوادم صوت لينكس منخفضة التأخير (Low-Latency Audio) وسهولة استخدام واجهات الويب العصرية:

1. **التعرف الدقيق على كرت الصوت الفعلي وإعادة الاتصال بالبفلة (Sound Card & Bluetooth Control):**
   - يكشف النظام آلياً عما إذا كان الصوت يخرج حالياً من كرت الصوت المدمج بالجهاز أو مكبر صوت البلوتوث الخارجي.
   - يعرض مؤشر الحالة اللحظي وصفاً دقيقاً:
     - إشارة خضراء: `🟢 البفلة متصلة وجاهزة`
     - إشارة صفراء تحذيرية: `🟡 كرت صوت الجهاز (البفلة مفصولة)` مع زر إعادة الاتصال الفوري بالبفلة عن بُعد بنقرة واحدة دون الذهاب للسيرفر.

2. **تحكم الأعضاء المباشر بصوت الجهاز (Member Volume & Output Settings):**
   - يستطيع أي عضو في المكتب النقر على مؤشر الحالة أو شارة الصوت في الشريط العلوي لفتح نافذة إعدادات الصوت.
   - سلايدرات صوت متزامنة تماماً في الاتجاهين مع تدرج لوني يتبع القيمة المحددة بدقة.

3. **نافذة الإجراءات والعدادات الروتينية السريعة (Routine Actions):**
   - قسم مخصص للعمليات السريعة ذات الأرقام المتغيرة (مثل: *"أين هو جهاز رقم X"*, *"تم إنجاز 70 جهاز إلى الآن"*, *"يوجد 10 أجهزة لم يتم البدء بها"*).
   - توفر أزرار زيادة ونقصان `+` و `-` مع كتابة مباشرة، معاينة حية للنص المتولد بالرقم الفعلي، زر استماع تجريبي محلي، وبث مباشر للبفلة.
   - إمكانية الإضافة والتعديل والحذف لكافة القوالب الروتينية.

4. **الاقتراحات السريعة للنطق الحر (Quick Snippets):**
   - أزرار مقترحة تظهر أعلى صندوق النطق الحر، يستطيع العضو النقر عليها ليتم إدراج النص عند موضع المؤشر بالضبط ومتابعة الكتابة بعدها بسلاسة، مع إمكانية إضافة وحذف الاقتراحات بحرية.

5. **تسجيل فويس مباشر للبفلة للإدارة مع الحذف التام (Admin Live Mic Broadcast):**
   - زر طلب إذن الميكروفون مجدداً عند حظر الصلاحية بالمتصفح.
   - **المعاينة الافتراضية عبر سماعات جهاز الإدارة حصراً (سماعات اللابتوب أو الهاتف)** لضمان الاستماع للرسالة بسرية تامة، مع خيار تجربة العينة على البفلة، ثم البث النهائي.
   - **سياسة الحذف الصارمة (Zero Retention):** يُحذف ملف التسجيل الصوتي نهائياً فور انتهاء النطق دون أي تخزين للحفاظ على الخصوصية.

6. **نموذج الذكاء الاصطناعي العصبي للصوت (AI Neural TTS):**
   - تحويل النص لصوت بأعلى جودة بشرية باستعمال نموذج `Microsoft Edge Neural TTS` بنقاء 24,000 Hz.
   - الكشف التلقائي عن اللغة: إذا كانت الحروف عربية $\leftarrow$ محرك عربي، وإذا كانت إنجليزية $\leftarrow$ محرك إنجليزي.

7. **تحكم مستقل بمستوى صوت نغمات التنبيه (Chime Volume Control):**
   - شريط تحكم مخصص لمستوى صوت النغمات المسبقة (Airport, Bell, Alert) مستقلاً عن مستوى صوت الكلام البشري.

8. **تطبيق مانع الإزعاج الموحد على الجمل والنطق الحر (Universal Cooldown Timer):**
   - عداد زمني موحد يمنع تكرار النداءات ويطبق على الجمل الثابتة، النطق الحر، والإجراءات الروتينية.

9. **توحيد الجمل وإضافة تصنيف "غير مصنف" (Single Title & Text Presets):**
   - نافذة إضافة وتعديل الجمل مبسطة: عنوان واحد فقط، ونص نطق واحد فقط، ثابتة لا تتغير بتغيير لغة العرض، مع خيار التصنيف **"غير مصنف"**.

10. **تأكيد الحذف لسجلات العمليات (Audit Deletion Confirmation):**
    - نوافذ تأكيد منبثقة قبل حذف أي سجل أو مسح كافة السجلات لمنع الحذف العرضي.

11. **واجهة إدارية بدون مصطلحات معقدة والعنوان بالإنجليزية دوماً:**
    - العنوان بجانب الشعار دائماً: **Kernel Ping Center** وإزالة شارة "لوحة مشفرة".

## 🛠️ متطلبات التشغيل السريع (Quick Start)

### تشغيل بيئة التطوير المحلية:
```bash
cd /home/moayad/kernelping
./run.sh
```
- الواجهة العامة: `http://localhost:5173/`
- لوحة الإدارة: `http://localhost:5173/admin`
- موثق الـ API: `http://localhost:8000/docs`

### تشغيل بيئة الإنتاج الموحدة:
```bash
cd /home/moayad/kernelping
./start_production.sh
```
أو عبر خدمة النظام:
```bash
sudo systemctl restart kernelping.service
```
