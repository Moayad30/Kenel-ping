## 🚀 نظرة عامة على النظام والمميزات المطورة

1. **إدارة وترتيب الجمل الثابتة وترقيمها (Presets Numbering & Reordering):**
   - عداد رقمي يوضح العدد الكلي للجمل في لوحة الإدارة.
   - ترقيم تسلسلي لكل جملة (`#`) لسهولة الفهرسة والتنسيق.
   - أزرار إعادة الترتيب اللحظية للأعلى والأسفل (Move Up / Down) مع حفظ تلقائي على السيرفر لتنعكس في واجهة الأعضاء تحت تصنيف "الكل" (All).

2. **التصميم الأفقي المتناسق لقوالب العمليات (Routine Actions):**
   - خط ناعم ومريح بدون تضخيم (`font-normal`) وقابل للالتفاف التلقائي (`break-words whitespace-normal`) مع الحفاظ على الأناقة المدمجة للبطاقة.

3. **إشعارات متمركزة بدقة في منتصف الشاشة (Centered Toasts):**
   - معالجة محاذاة الإشعارات لتتمركز هندسياً في منتصف أعلى الشاشة متوافقة تماماً مع الاتجاهين العربي والإنجليزي.

4. **إغلاق النوافذ المنبثقة بزر `Esc`:**
   - دعم الخروج السريع من كافة النوافذ المنبثقة وصناديق الحوار والتأكيد بمجرد الضغط على زر Escape.

5. **استخدام بروتوكول HTTP القياسي:**
   - تشغيل النظام على خادم HTTP الخفيف والمباشر على المنفذ `5173`.

## 🛠️ متطلبات التشغيل السريع (Quick Start)

### تشغيل بيئة التطوير:
```bash
cd /home/moayad/kernelping
./run.sh
```
- الواجهة العامة: `http://localhost:5173/`
- لوحة الإدارة: `http://localhost:5173/admin`
- موثق الـ API: `http://localhost:8000/docs`

### تشغيل بيئة الإنتاج:
```bash
cd /home/moayad/kernelping
./start_production.sh
```
أو عبر خدمة النظام:
```bash
sudo systemctl restart kernelping.service
```
