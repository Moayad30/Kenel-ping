## 🚀 أبرز المميزات والإمكانيات المعتمدة (Key System Capabilities)

1. **نطق عصبي واقعي فائق النقاء بالذكاء الاصطناعي:**
   - اعتماد صوت حامد السعودي الفصيح (`ar-SA-HamedNeural`) وصوت أندرو الإنجليزي المعياري (`en-US-AndrewMultilingualNeural`) بنقاء 24kHz.
2. **توقيت النغمة المتزامن (Synchronized Pre-Chime Timing) وضبط الصمت:**
   - إنهاء مشكلة الفراغ الصامت أو الانتظار بعد رنين النغمة؛ حيث تنطلق النغمة فور جهوزية الصوت ويبدأ الكلام فوراً بدون أي تأخير.
   - إضافة عدادات دقيقة لـ "زمن الصمت التمهيدي (Pre-chime silence)" و "زمن الصمت البيني (Inter-chime delay)" لحل مشكلة اقتطاع الحرف الأول نتيجة سكون كرت الصوت والبفلة.
3. **تضخيم الصوت حتى 150% (Audio Amplification Boost):**
   - إمكانية رفع مستوى الصوت حتى 150% لتغطية البيئات الصاخبة ومختبرات الصيانة المزدحمة عبر WirePlumber (`wpctl -l 1.5`).
4. **زر الإيقاف الفوري الشامل (Emergency Instant Audio Stop):**
   - إيقاف أي صوت جاري فوراً في أجزاء من الثانية من خلال زر أحمر نابض متاح لكافة الأعضاء والمشرفين في الشريط العلوي.
5. **تفاعل لحظي 100% دون تحديث الصفحة:**
   - تطبيق التحديث التفاؤلي اللحظي (Optimistic UI) بالتكامل مع مقابس الويب (WebSockets) ذاتية إعادة الاتصال ومزامنة احتياطية كل 1.5 ثانية.
6. **سجل عمليات وتدقيق لحظي ضخم يتسع لـ 50,000 نداء مع عرض النصوص كاملة:**
   - إحصائيات متطابقة رياضياً بنسبة 100% ومحدثة حياً كل ثانيتين في لوحة الإدارة مع عرض الرسائل كاملة مهما بلغ طولها بدون اقتطاع.
7. **نافذة القوالب السريعة ونداءات الأجهزة:**
   - نافذتان متجاورتان للقوالب والعدادات ("أين هو جهاز رقم X"، "تم إنجاز 70 جهاز"، إلخ) وصندوق النطق الحر مع التشكيل الآلي واقتراحات النصوص السريعة وتنبيه التوليد السحابي.
8. **إدارة سلسة للتصنيفات والجمل:**
   - إمكانية طي التصنيفات بسهم ناعم، إخفاء التصنيفات غير الضرورية، اعتماد المعرفات الرقمية (`Numeric IDs`) للجمل وملفاتها الصوتية (`1_ar.mp3`, `2_ar.mp3`...)، نافذة تأكيد حذف مخصصة لكل جملة، وزر "توسيع/طي كافة البطاقات"، وسهم تفاعلي ذكي يظهر فقط للجمل المقتطعة.

## 🛠️ سجل التحديات والحلول الهندسية المنجزة (Engineering Evolution Log)

خلال مسيرة بناء وضبط النظام، تم حل ومعالجة مجموعة من التحديات المحورية بدقة واحترافية:

| المشكلة المرصودة | سببها الهندسي | الحل المطبق والمعتمد |
| :--- | :--- | :--- |
| **توقف عداد الإحصائيات عند 100** | اقتطاع دالة `save_audit` في الباك إند للسجل عند `[-100:]`. | إلغاء السقف ورفع الحد إلى 50,000 عملية، وإضافة مزامنة حية كل ثانيتين. |
| **جمود حالة الأزرار وعدم تحديثها إلا بتحديث الصفحة** | انقطاع اتصال مقبس الويب عند سكون المتصفح دون إعادة اتصال. | تطبيق التحديث التفاؤلي الفوري + حلقة إعادة الاتصال التلقائية + استدعاء دوري كل 1.5 ثانية. |
| **عدم استقرار ميزة تسجيل الرسائل الصوتية الحية للبفلة** | قيود المتصفحات التي تمنع واجهة الميكروفون برمجياً عبر الـ HTTP العادي بدون HTTPS. | **إزالة الميزة نهائياً**، والاعتماد بالكامل على النطق العصبي الفائق الجودة الذي لا يحتاج أذونات ميكروفون. |
| **تعقيد إدخال معرف التصنيف (`Category ID`)** | مطالبة المشرف بكتابة Slug يدوي في النافذة. | حذف الحقل وتوليد الـ Slug تلقائياً من الاسم الإنجليزي والتحقق من عدم تكراره. |
| **اختلاف النصوص وميل الإشعارات** | تفاوت الترجمات وخلل في تموضع الإشعارات عبر الشاشة. | توحيد ملف الترجمة وتوسيط الإشعارات هندسياً في منتصف الشاشة بدقة متناهية. |
| **تضارب خط القوالب وشريط التمرير الأفقي** | استخدام عناصر بأحجام ثابتة غير مرنة. | تفعيل التفاف العناصر تلقائياً (`flex-wrap`) مع ضبط نعومة الخط وإضافة زر السهم التفاعلي. |
| **صعوبة إغلاق النوافذ المنبثقة** | قصر الإغلاق على النقر بالماوس. | تفعيل زر الهروب (`Esc`) في لوحة المفاتيح لإغلاق أي نافذة أو صندوق تأكيد فورياً. |

## ⚡ التشغيل السريع (Quick Run)

### 1. بيئة التطوير المحلية (Local Development):
```bash
./run.sh
```
- واجهة الأعضاء: `http://localhost:5173/`
- لوحة الإدارة: `http://localhost:5173/admin`

### 2. بيئة الإنتاج الموحدة للأجهزة والجوالات (Production Mode):
```bash
./start_production.sh
```
- سيكتشف السكربت عنوان الـ IP المحلي تلقائياً ويبني الواجهة ويوفر الرابط لجميع أجهزة وشاشات وهواتف المكتب المتصلة بنفس شبكة الـ Wi-Fi.
