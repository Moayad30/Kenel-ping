## 🚀 نظرة عامة على النظام والمميزات المطورة

**Kernel Ping** يربط بين سرعة خوادم صوت لينكس منخفضة التأخير (Low-Latency Audio) وسهولة استخدام واجهات الويب العصرية:

1. **التعرف الدقيق على كرت الصوت الفعلي (Hardware Sound Card Detection):**
   - يكشف النظام آلياً عما إذا كان الصوت يخرج حالياً من كرت الصوت المدمج بالجهاز (مثل `HD-Audio Generic ALC256 Analog`) أو مكبر صوت خارجي / سماعة بلوتوث.
   - يعرض مؤشر الحالة اللحظي وصفاً دقيقاً: *"صوت الجهاز جاهز"* أو *"البفلة جاهزة"*.

2. **تحكم الأعضاء المباشر بصوت الجهاز (Member Volume & Output Settings):**
   - يستطيع أي عضو في المكتب النقر على مؤشر الحالة أو شارة الصوت في الشريط العلوي لفتح نافذة إعدادات الصوت.
   - تتيح النافذة معرفة كرت الصوت المتصل بالضبط، والتحكم بسلايدر الصوت المباشر للجهاز مع أزرار سريعة وكتم الصوت.

3. **تسجيل فويس مباشر للبفلة للإدارة مع الحذف التام (Admin Live Mic Broadcast):**
   - تم دمج الواجهة الرئيسية الكاملة في قسم الإدارة.
   - يستطيع المسؤول تسجيل مقطع صوتي مباشر من ميكروفون جهازه، معاينته بالاستماع قبل الإرسال، ثم بثه فوراً لمكبر الصوت.
   - **سياسة الحذف الصارمة (Zero Retention):** يُحذف ملف التسجيل الصوتي نهائياً فور انتهاء النطق دون أي تخزين للحفاظ على الخصوصية.

4. **تحكم مستقل بمستوى صوت نغمات التنبيه (Chime Volume Control):**
   - شريط تحكم مخصص لمستوى صوت النغمات المسبقة (Airport, Bell, Alert) مستقلاً عن مستوى صوت الكلام البشري.

5. **تطبيق مانع الإزعاج الموحد على الجمل والنطق الحر (Universal Cooldown Timer):**
   - عداد زمني موحد يمنع تكرار النداءات ويطبق على الجمل الثابتة وصندوق النطق الحر.
   - إظهار عداد الثواني التنازلي التفاعلي المباشر داخل أزرار الإرسال.

6. **توحيد الجمل وإضافة تصنيف "غير مصنف" (Single Title & Text Presets):**
   - نافذة إضافة وتعديل الجمل أصبحت مبسطة: عنوان واحد فقط، ونص نطق واحد فقط، ثابتة لا تتغير بتغيير لغة العرض.
   - خيار التصنيف يضم **"غير مصنف"** للجمل العامة.
   - كشف تلقائي ذكي لنوع لغة الجملة (عربي -> محرك عربي، إنجليزي -> محرك إنجليزي).

7. **تأكيد الحذف لسجلات العمليات (Audit Deletion Confirmation):**
   - نوافذ تأكيد منبثقة قبل حذف أي سجل أو مسح كافة السجلات لمنع الحذف العرضي.

8. **واجهة إدارية واضحة ومناسبة للمكاتب:**
   - إزالة المصطلحات التقنية والبرمجية المعقدة لتقديم بيئة استخدام مريحة ومفهومة لجميع الكوادر.

## 🛠️ متطلبات التشغيل السريع (Quick Start)

### تشغيل بيئة التطوير المحلية:
```bash
cd /home/moayad/kernelping
./run.sh
```
- الواجهة العامة: `http://localhost:5173/`
- لوحة الإدارة: `http://localhost:5173/admin`
- موثق الـ API: `http://localhost:8000/docs`

### تشغيل بيئة الإنتاج الموحدة:
```bash
cd /home/moayad/kernelping
./start_production.sh
```
أو عبر خدمة النظام:
```bash
sudo systemctl restart kernelping.service
```
