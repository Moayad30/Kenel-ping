## 🚀 نظرة عامة سريعة (Executive Summary)

**Kernel Ping** هو حل إذاعي مكتبي يجمع بين أداء نظم لينكس المنخفضة التأخير (Low-Latency Linux Audio) وقوة واجهات الويب الحديثة التفاعلية:
- **المطور والمشغل الحالي:** فيدورا كيدي 44 وركستيشن (Fedora KDE 44 Workstation).
- **البيئة المستهدفة للإنتاج المستقبلي:** سيرفر دبيان 13 (Debian 13 Trixie Server).
- **الركيزة الصوتية:** خادم الصوت الحديث `PipeWire` ومتحكم العقد `WirePlumber` عبر مشغل `mpv`.
- **الذكاء الاصطناعي الصوتي:** أصوات عصبية فائقة الوضوح عبر محرك `Edge-TTS` مع نموذج التشكيل اللغوي `Mishkal`.
- **الأمان الهيكلي:** عزل تام بنمط **Stealth Admin** حيث لا تحتوي الواجهة العامة للأعضاء على أي رابط، أيقونة، أو أثر لوجود لوحة تحكم.

## ⚡ التشغيل السريع (Quick Start)

### 1. تشغيل بيئة التطوير (Development):
```bash
./run.sh
```
- واجهة الأعضاء: `http://localhost:5173/`
- لوحة الإدارة: `http://localhost:5173/admin`
- واجهة الـ API: `http://localhost:8000/docs`

### 2. تشغيل بيئة الإنتاج الموحدة (Production SPA):
```bash
./start_production.sh
```
- واجهة الإنتاج الموحدة (Frontend + API): `http://localhost:8000/` أو `http://kernelping.local:8000/`
