## 🚀 نظرة عامة على النظام والمميزات المطورة

**Kernel Ping Center** يربط بين سرعة خوادم صوت لينكس منخفضة التأخير (Low-Latency Audio) وسهولة استخدام واجهات الويب العصرية:

1. **التعرف الدقيق على كرت الصوت الفعلي النشط (Real Sound Card Detection):**
   - يكشف النظام آلياً وبدقة اسم كرت الصوت الفعلي الذي يخرج منه الصوت بالجهاز (مثلاً كرت الصوت المدمج أو مخرج HDMI أو البفلة المتصلة).
   - يعرض مؤشر الحالة اللحظي وصفاً دقيقاً:
     - إشارة خضراء: `🟢 البفلة متصلة وجاهزة`
     - إشارة صفراء تحذيرية: `🟡 كرت صوت الجهاز (البفلة مفصولة)`
   - تم إلغاء ميزة إعادة الاتصال بالبفلة غير المستقرة وتنظيف الواجهة لضمان البساطة والاعتمادية.

2. **تسجيل فويس مباشر للبفلة للإدارة مع دعم الهواتف المحمولة (Admin Live Voice Broadcast & Mobile Support):**
   - **بث مباشر وفوري بدون تأخير أو معاينة:** يسجل المسؤول الفويس ويبثه مباشرة للبفلة دون الحاجة لمعاينة صوتية تعطل سير العمل.
   - **دعم متصفحات الجوال عبر HTTPS:** توفير خادم آمن مدمج بشهادات SSL للوصول عبر `https://<IP>:5173/admin` ليتمكن متصفح كروم على الهاتف من طلب إذن الميكروفون بسلاسة، مع توفير خيارات إرشادية بديلة عبر Chrome Flags.
   - **سياسة الحذف الصارمة (Zero Retention):** يُحذف ملف التسجيل الصوتي نهائياً فور انتهاء النطق دون أي تخزين للحفاظ على الخصوصية.

3. **نافذة نداءات الأجهزة والروتين السريعة (Routine Actions Window):**
   - قسم مخصص للعمليات السريعة ذات الأرقام المتغيرة (مثل: *"أين هو جهاز رقم X"*, *"تم إنجاز 70 جهاز إلى الآن"*, *"يوجد 10 أجهزة لم يتم البدء بها"*).
   - **خط كبير ونزول أسطر متعددة (Multi-line Wrapping):** يظهر نص النداء كاملاً بخط عريض وواضح بدون أي قص أو اختصار، مع أزرار الزيادة والنقصان `+` و `-`.
   - تأكيد حواري صريح عند حذف أي قالب لمنع الحذف بالخطأ.

4. **صندوق النطق الحر مع الاقتراحات السريعة النظيفة (Free Speech Box):**
   - **ثبات الرسالة بعد النطق:** تظل الرسالة مكتوبة في الصندوق بعد نطقها لإمكانية إعادة استخدامها أو التعديل عليها بسهولة.
   - **أزرار اقتراحات سريعة بدون أيقونات:** أزرار نصية نظيفة وأنيقة تدرج النص فوراً بنقرة واحدة عند موضع مؤشر الكتابة.
   - زر إضافة الاقتراح بإشارة زائد واحدة فقط: `+ إضافة اقتراح`.
   - منع الضغط المتكرر أثناء تشغيل أي رسالة صوتية أخرى في المكتب.

5. **الجمل الثابتة فائقة السرعة والمحملة مسبقاً (Pre-cached Offline Presets):**
   - إشارة واضحة توضح أن هذه الجمل محملة محلياً (Pre-cached) لتوفير أسرع زمن استجابة ونطق فوري دون أي تأخير زمني.
   - نافذة إضافة وتعديل الجمل مبسطة: عنوان واحد فقط، ونص نطق واحد فقط، ثابتة لا تتغير بتغيير لغة العرض، مع خيار التصنيف **"غير مصنف"**.

6. **نموذج الذكاء الاصطناعي العصبي للصوت (AI Neural TTS):**
   - تحويل النص لصوت بأعلى جودة بشرية باستعمال نموذج `Microsoft Edge Neural TTS` بنقاء 24,000 Hz.
   - الكشف التلقائي عن اللغة: إذا كانت الحروف عربية $\leftarrow$ محرك عربي، وإذا كانت إنجليزية $\leftarrow$ محرك إنجليزي.

7. **تحكم مستقل بمستوى صوت نغمات التنبيه (Chime Volume Control):**
   - شريط تحكم مخصص لمستوى صوت النغمات المسبقة (Airport, Bell, Alert) مستقلاً عن مستوى صوت الكلام البشري.

8. **تأكيد الحذف لسجلات العمليات (Audit Deletion Confirmation):**
   - نوافذ تأكيد منبثقة قبل حذف أي سجل أو مسح كافة السجلات لمنع الحذف العرضي.

9. **واجهة إدارية أنيقة والعنوان بالإنجليزية دوماً:**
   - العنوان بجانب الشعار دائماً: **Kernel Ping Center** وإزالة شارة "لوحة مشفرة".

## 🛠️ متطلبات التشغيل السريع (Quick Start)

### تشغيل بيئة التطوير المحلية:
```bash
cd /home/moayad/kernelping
./run.sh
```
- الواجهة العامة: `https://localhost:5173/` أو `http://localhost:5173/`
- لوحة الإدارة من الكمبيوتر أو الهاتف: `https://<SERVER-IP>:5173/admin`
- موثق الـ API: `http://localhost:8000/docs`

### تشغيل بيئة الإنتاج الموحدة:
```bash
cd /home/moayad/kernelping
./start_production.sh
```
أو عبر خدمة النظام:
```bash
sudo systemctl restart kernelping.service
```
