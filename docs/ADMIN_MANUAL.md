# 🔐 دليل الإدارة والتحكم الشامل (Stealth Admin Manual)

يوفر مركز الإدارة المخفي **Stealth Admin Center** تحكماً دقيقاً وفورياً بكافة معايير الصوت، الجمل الإذاعية، والتصنيفات، مع الحفاظ على سرية لوحة التحكم وعزلها التام عن أعضاء المكتب.

---

## 🚪 1. الوصول والمصادقة (Access & Authentication)

- **رابط الدخول الحصري:** `http://kernelping.local:8000/admin` (أو `http://localhost:5173/admin` في بيئة التطوير).
- **بيانات الاعتماد الافتراضية:**
  - **اسم المستخدم (Username):** `admin`
  - **كلمة المرور (Password):** `kernel2026`

> [!IMPORTANT]
> **تغيير كلمة المرور الافتراضية للإنتاج:**
> يمكن تغيير اسم المستخدم وكلمة السر ومفتاح التشفير بسهولة عبر تمرير متغيرات البيئة قبل تشغيل التطبيق أو داخل ملف الخدمة:
> ```bash
> export KERNELPING_ADMIN_USER="superadmin"
> export KERNELPING_ADMIN_PASS="StrongSecretPassword2026!"
> export KERNELPING_JWT_SECRET="YourVeryLongRandomSecretKeyHere"
> ```

## 🎚️ 2. تبويب إعدادات وهندسة الصوت (Audio Settings)

1. **التحكم بمستوى صوت السيرفر (Server Volume):**
   - سلايدر تفاعلي مباشر يتحكم بمخرج الصوت الحقيقي للنظام (`wpctl set-volume`).
   - يتزامن تلقائياً وبشكل حي إذا تم تغيير الصوت من أزرار الكيبورد بجهاز السيرفر.

2. **اختيار واختبار النماذج الصوتية العصبية (Neural TTS):**
   - اختيار الصوت العربي المفضل (`ar-SY-LaithNeural` أو `ar-SA-HamedNeural`).
   - اختيار الصوت الإنجليزي المفضل (`en-US-BrianMultilingualNeural` أو `en-US-AriaNeural`).
   - **زر تجربة الصوت الحية (Test Voice ▶):** يتيح للمسؤول سماع نبرة الصوت المختار فوراً في سماعة المكتب قبل اعتماده.

3. **نغمات التنبيه وإيقاظ البلوتوث (Chimes & Bluetooth Wake-up):**
   - تفعيل أو تعطيل نغمة التنبيه المسبقة مع إمكانية اختيار نوع النغمة (مطار، جرس، أو إنذار) وزر للاستماع الفوري إليها.
   - تفعيل وضع إيقاظ البلوتوث الذي يمنح مستقبلات الصوت A2DP مهلة 400ms صمت لتنشيط مكبر الصوت قبل بدء الكلام.

4. **مانع الإزعاج والتكرار (Spam Cooldown):**
   - تفعيل / تعطيل مهلة الانتظار الإجبارية بين النداءات.
   - تحديد الثواني المطلوبة (مثلاً 10، 15، أو 30 ثانية).

## 📁 3. تبويب إدارة التصنيفات (Categories CRUD)

- **إضافة تصنيف جديد:** تحديد المعرف الفريد (ID)، الاسم بالعربية، الاسم بالإنجليزية، الأيقونة المعبرة، واللون المميز.
- **تعديل التصنيف:** إمكانية تغيير أسماء التصنيفات وترتيب ظهورها في الواجهة العامة.
- **حذف التصنيف:** إزالة التصنيف مع تحذير تأكيدي قبل الحذف.

---

## 🎙️ 4. تبويب إدارة الجمل الثابتة والتخزين (Presets CRUD)

- **إضافة جملة جديدة:** كتابة عنوان الجملة ونصها المنطوق، واختيار تصنيفها وأيقونتها. بمجرد الحفظ، يقوم النظام فوراً بتوليد ملف MP3 عالي الجودة وتخزينه على القرص.
- **استقلالية لغة الجملة:** تبقى الجملة ثابتة بنصها الأصلي (عربياً كان أو إنجليزياً) ولا تتغير بتغيير لغة الموقع.
- **إعادة بناء الكاش (Rebuild Audio):**
  - زر مخصص بجانب كل جملة لإعادة توليد ملف الـ MP3 في حال تم تعديل نصها أو تغيير الصوت الأساسي.
  - زر عام: `إعادة توليد وتخزين كافة الأصوات` لتحديث كافة ملفات النظام الصوتية دفعة واحدة.

---

## 📋 5. تبويب سجل العمليات والتدقيق (Activity Audit)

- **إحصائيات الإذاعة:** عرض إجمالي النداءات المنفذة، وعدد الجمل الثابتة مقابل النطق الحر.
- **جدول السجل الحي:** يعرض آخر العمليات مع التوقيت، عنوان النداء، نوعه، النص المنطوق، لغة النطق، وعنوان IP الخاص بجهاز المُرسل.
- **إدارة وحذف السجلات:**
  - **حذف سجل محدد:** زر سلة المهملات بجانب أي عملية لحذفها منفردة من السجل.
  - **مسح السجل بالكامل (Clear All Logs):** زر بأعلى الجدول لمسح أرشيف العمليات كاملاً بعد التأكيد.
